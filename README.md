# 📊 Data Analysis Projects Portfolio (Excel)

This repository contains two Excel-based data analysis projects focused on understanding salary trends, job market demand, and skill requirements in data-related roles. These projects demonstrate my ability to clean data, analyze it using Excel tools, and derive meaningful insights for real-world decision-making.

---

## 📁 Project 1: Excel Salary Dashboard

### Overview

In this project, I built an interactive Excel dashboard to help job seekers explore salary trends across different data-related roles. The dashboard allows users to compare salaries based on job titles, locations, and job types, enabling informed career and compensation decisions.

### What I Did

- Analyzed real-world data science job salary data
- Created a structured salary dashboard in Excel
- Used charts to visualize salary comparisons and geographic trends
- Applied formulas and functions to calculate metrics such as median salaries
- Implemented data validation to allow user-friendly filtering and interaction

### Skills Demonstrated

- Excel Charts and Dashboard Design
- Formulas and Functions
- Data Validation
- Data Interpretation and Storytelling

---

## 📁 Project 2: Data Jobs Market Analysis

### Overview

This project focuses on analyzing the data science job market to understand how skills, location, and job roles impact salaries. The goal was to identify high-paying roles, in-demand skills, and regional salary trends using advanced Excel features.

### What I Did

- Cleaned and transformed raw job market data using Power Query
- Built a data model using Power Pivot
- Analyzed relationships between number of skills and salary levels
- Compared salary trends across regions
- Identified top skills and evaluated their impact on pay
- Used PivotTables, PivotCharts, and DAX measures for analysis

### Skills Demonstrated

- Power Query (ETL)
- Power Pivot & Data Modeling
- PivotTables & PivotCharts
- DAX (Data Analysis Expressions)
- Analytical Thinking and Business Insight Generation
